# The Computation Society website

A small static site generated by `events.py` (Python 3, standard library only).

```
events.json        ← the list of events (edit this or use the commands below)
events.py          ← adds/removes events and builds the site
templates/         ← page layouts (base.html wraps index.html and events.html)
static/style.css   ← stylesheet
site/              ← GENERATED output — this is the folder to publish
```

## Updating events

```bash
python events.py add        # asks for title, date, time, location, description, link
python events.py list       # shows all events with numbers
python events.py remove 2   # removes event #2
```

You can also skip the prompts:

```bash
python events.py add --title "Hack Night" --date 2026-11-20 --time "6:00 PM" \
    --location "Room 101" --description "Bring a laptop and a project." --link ""
```

Or edit `events.json` by hand and then run `python events.py build`.

Dates use `YYYY-MM-DD`. Events dated today or later show under **Upcoming**; older
ones move to **Past** automatically the next time the site is built. The home
page's "Next up" card always shows the soonest upcoming event.

After any change, commit both `events.json` and the `site/` folder.

## Editing pages

Change text in `templates/index.html` or `templates/events.html`, then run
`python events.py build`. Placeholders like `{{ upcoming_events }}` are filled in
by the script — leave them in place. Don't edit files in `site/` directly; they
are overwritten on every build.
